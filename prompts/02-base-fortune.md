One heading, kept deliberately small:

Reasons must be traceable to the chart, not floating predictions — and if a
section cannot be traced, the honesty clause makes it say so instead of
filling the gap.

## If this loses grounding

Split further — one area per conversation. The 2026-10-01 run showed the
failure is graded, not binary: a narrow query grounded with 5 citations, the
five-section book request grounded with 0. Intermediate sizes sit in between,
and where the cliff is has not been measured.
